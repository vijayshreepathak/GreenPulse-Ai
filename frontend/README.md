# GreenPulse AI Frontend

React + Vite dashboard for the GreenPulse AI MVP.

## Run

```bash
npm install
npm run dev
```

The frontend defaults to `http://localhost:8000` for backend API calls. Set `VITE_API_BASE_URL` to override it.

## Optional Map

Place `thapar_zones.geojson` in `public/` to enable the campus map.
